# Sujets PFE — Open Source

Catalogue de 2287 sujets de projet de fin d'études (PFE) en Intelligence Artificielle, AI Agents, DevOps, Cybersécurité et Data Analysis, réalisables avec des outils 100 % open source.

Les sujets sont proposés à quatre niveaux : 300 en licence (4 mois), 187 en ingénieur ou master (6 mois) et 1800 en parcours recherche (6 mois).

Live: https://sujetpfe.subul.uk

## Liens profonds

Les filtres sont reflétés dans l'URL, ce qui permet de partager une sélection ou d'y renvoyer
depuis les académies Subul :

| Paramètre | Valeurs | Exemple |
|---|---|---|
| `domain` | `ai`, `agents`, `devops`, `cyber`, `data` | `?domain=cyber` |
| `type` | `PFE Licence`, `PFE Ingénieur ou Master`, `PFE de recherche` | `?type=PFE%20Licence` |
| `q` | texte libre (titre, stack ou référence) | `?q=Kubernetes`, `?q=PFE-042` |
| `sort` | `id`, `title`, `months` | `?sort=months` |

Exemple complet : https://sujetpfe.subul.uk/?domain=ai&q=PyTorch&type=PFE%20Licence
